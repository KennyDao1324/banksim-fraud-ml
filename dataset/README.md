# BankSim dataset

- Canonical source: https://www.kaggle.com/datasets/ealaxi/banksim1
- Research description: López-Rojas and Axelsson, *BankSim: A Bank Payment Simulation for Fraud Detection Research* (2014)
- Type: synthetic agent-based bank-payment transactions
- Expected file: `data/raw/bs140513_032310.csv`
- Download fallback used by this project: https://github.com/niravdedhiya/Fraud-Detection-BankSim

The raw data is ignored by Git. Customer, merchant and constant ZIP identifiers are excluded from the baseline.
